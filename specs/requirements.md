# Требования к проекту Pastebin Mermaid

## Общее описание

Сервис для обмена текстовыми фрагментами (аналог pastebin) с поддержкой подсветки синтаксиса и рендеринга диаграмм на клиенте. На первом этапе поддерживается формат Mermaid.

---

## Стек технологий

- **Backend:** Python, FastAPI
- **Frontend:** Vue 3
- **БД:** SQLite
- **Рендеринг диаграмм:** Mermaid.js (клиентский рендеринг)
- **Подсветка синтаксиса:** highlight.js или Prism.js

---

## Функциональные требования

### 1. Создание пасты

- Пользователь вводит текст в редактор
- Выбирает тип содержимого:
  - Код (с выбором языка для подсветки синтаксиса)
  - Mermaid-диаграмма
  - Обычный текст
- Выбирает срок жизни пасты (TTL):
  - 1 час
  - 1 день
  - 1 неделя
  - 1 месяц
  - Бессрочно
- **Live preview:** при выборе типа Mermaid диаграмма рендерится в реальном времени рядом с редактором
- Авторизация не требуется — пасты создаются анонимно
- После сохранения пользователь получает ссылку на пасту

### 2. Просмотр пасты

- По уникальной ссылке открывается страница просмотра
- Для Mermaid-паст отображается:
  - Отрендеренная диаграмма с поддержкой масштабирования (zoom in/out, pan)
  - Исходный код диаграммы рядом или под рендером
- Для кода — подсветка синтаксиса
- Для обычного текста — отображение как есть
- Кнопка копирования содержимого в буфер обмена
- Отображение метаданных: тип содержимого, дата создания, оставшееся время жизни

### 3. Редактирование

- Редактирование паст после создания **не поддерживается**
- Пасты доступны только для чтения

### 4. Удаление паст (TTL)

- Пасты автоматически удаляются по истечении выбранного срока
- Удаление выполняется фоновой задачей на бэкенде
- Просроченные пасты возвращают 404

## API

### Эндпоинты

| Метод | URL | Описание |
|-------|-----|----------|
| `POST` | `/api/pastes` | Создание новой пасты |
| `GET` | `/api/pastes/{id}` | Получение пасты по ID |

### Создание пасты

**Request:**
```json
{
  "content": "string",
  "content_type": "code" | "mermaid" | "text",
  "language": "python",  // только для content_type=code
  "ttl": "1h" | "1d" | "1w" | "1m" | "never"
}
```

**Response:**
```json
{
  "id": "abc123",
  "url": "/p/abc123",
  "created_at": "2026-03-03T12:00:00Z",
  "expires_at": "2026-03-04T12:00:00Z"
}
```

### Получение пасты

**Response:**
```json
{
  "id": "abc123",
  "content": "graph TD; A-->B;",
  "content_type": "mermaid",
  "language": null,
  "created_at": "2026-03-03T12:00:00Z",
  "expires_at": "2026-03-04T12:00:00Z"
}
```

## Модель данных

### Таблица `pastes`

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | TEXT (PK) | Уникальный короткий идентификатор |
| `content` | TEXT | Содержимое пасты |
| `content_type` | TEXT | Тип: `code`, `mermaid`, `text` |
| `language` | TEXT (nullable) | Язык программирования (для code) |
| `created_at` | DATETIME | Время создания |
| `expires_at` | DATETIME (nullable) | Время истечения (null = бессрочно) |

---

## Страницы фронтенда

### Главная (`/`)
- Редактор для ввода содержимого
- Выбор типа содержимого (code / mermaid / text)
- Выбор языка (при типе code)
- Выбор TTL
- Live preview для Mermaid (split view: редактор слева, превью справа)
- Кнопка "Создать"

### Просмотр пасты (`/p/{id}`)
- Для mermaid: отрендеренная диаграмма (с zoom/pan) + исходный код
- Для code: подсвеченный код
- Для text: обычный текст
- Метаданные (тип, дата создания, время до удаления)
- Кнопка "Скопировать"
- Кнопка "Создать новую" (ведёт на главную)

---

## Нефункциональные требования

- Генерация коротких уникальных ID для паст (например, 8 символов, base62)
- Ограничение размера пасты (например, 512 KB)
- Фоновая очистка просроченных паст
- Статическая раздача фронтенда через FastAPI или nginx
- Простой деплой: один процесс (FastAPI) + файл SQLite
